[crates.io](https://crates.io/crates/proptest) ~ [docs.rs](https://docs.rs/proptest/latest/proptest/) ~ [source](https://github.com/proptest-rs/proptest)

Proptest is a hypothesis-like property-based testing and shrinking crate.
It allows you define various strategies and combined strategies
to bring your crate testing to the next level.

We recommend checking out the [proptest book](https://proptest-rs.github.io/proptest/proptest/index.html)
to get started.

### [Kim Tae-Geun et al., Peroxide: A Batteries-Included Numerical Computing Library for Rust, JOSS, 11(124)](https://doi.org/10.21105/joss.10366)

Peroxide is a Rust numerical computing library
that integrates eight domains in one crate: linear
algebra, ordinary differential equation (ODE) solving,
adaptive quadrature, spline interpolation with exact polynomial calculus,
root-finding, forward-mode automatic differentiation (AD),
statistics, and multi-format DataFrame I/O.

### [Koundinyan Sri, Elibol Melih, and Bentz Jonathan, Introducing CUDA Rust: Two Tracks for Writing GPU Kernels](https://developer.nvidia.com/blog/introducing-cuda-rust-two-tracks-for-writing-gpu-kernels/)

A brief introduction on writing GPU kernels
with hands-on examples on using
[cutile-rs](https://github.com/NVlabs/cutile-rs)
and
[cuda-oxide](https://github.com/NVlabs/cuda-oxide).

### [Otálvaro Julián D. et al., pharmsol: A high-performance Rust library for pharmacokinetic and pharmacodynamic modeling and simulation, JOSS, 11(124)](https://doi.org/10.21105/joss.10580#)

Pharmsol is a library for pharmacokinetic/pharmacodynamic (PK/PD) simulation.
It provides the necessary tools and frameworks for defining, solving, and analyzing
compartmental models,
with support for differential equations, their analytical solutions,
and experimental support for stochastic differential equations.

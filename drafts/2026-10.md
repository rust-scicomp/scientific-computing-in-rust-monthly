## New releases

### Aphid 0.12.4 (https://mbb.cnrs.fr/aphid/)
Aphid is a statistical method described in https://doi.org/10.24072/pcjournal.359 to distinguish gene flow from incomplete lineage sorting in sibling species, answering whether discordant genetic ancestry is better explained by uneven recollection of shared ancient evolutionary events or by recent horizontal gene transfers.

### dogleg 0.1.0
The dogleg crate offers backend-agnostic Rust-native high quality unconstrained
nonlinear least-squares minimization. It currently supports the `faer` and
`nalgebra` backends and achieves the same result as Googles `Ceres` library
on the test suite.

### [Fastmash 0.2.0](https://crates.io/crates/fastmash)
Fastmash brings fast, repeatable statistics to shell pipelines. Written in Rust,
it summarizes, groups and reshapes delimited text and quoted CSV, with
percentiles, correlations, weighted means and pivot tables. It accepts GNU
datamash’s command language, so existing scripts can often switch by changing
one word. Software arithmetic keeps numerical results identical across supported
machines for the same input, settings and version. Use it to summarize
experimental data, compare datasets or check table health without writing a
separate analysis program.

### [Manuel Drehwald, When Safe Code is Fast - Scientific Computing in Rust, Talk at RustConf 2026](https://youtu.be/2Ws0ZS6EHkE?si=wJ79woAUtWHP123q)

The talk explores two new features of Rust:
computing derivatives with `std::autodiff`
and running code on GPUs via `std::offload`.
In both cases, safe Rust fares a lot better than unsafe Rust.

### [geo-ant, Powell’s Dogleg for Least Squares Minimization from Scratch](https://geo-ant.github.io/blog/2026/powells-dogleg-least-squares-from-scratch/)

Everything you ever needed to know and more about actually implementing a nonlinear
least squares solver using the Dogleg method by the author of the
[`dogleg`](https://docs.rs/dogleg/latest/dogleg/) crate. Needs no prerequisites
and goes from the basics down to the nitty-gritty implementation details that
are often left out of such tutorials.

### [Alan Yuan, Hardware-Aware Programming in Rust](https://medium.com/@alan0408yuan/hardware-aware-programming-in-rust-6e68a70c1535?postPublishedType=repub)

This post discusses practical tips for optimizing Rust code
for high performance computing with respect to the hardware it runs on,
with a specific focus on Apple M4 Pro Chips.
